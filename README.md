# Glossar Datenportal

Dieses Glossar erklärt die gemeinsamen Begriffe aus Datenpublikation,
Architektur, Betrieb und Themenintegration. Es richtet sich an Fachämter,
Datenlieferanten, Themenintegratoren und Betreiber.

Der Einstieg ist [das Biblios-Buch](docs/biblios/master.adoc). Die zentrale
Dokumentation bindet es als Glossar im Bereich «Datenlieferant» ein. Für eine
lokale Vorschau gelten die Hinweise im README des zentralen Repositorys
`datenportal-dokumentation`.

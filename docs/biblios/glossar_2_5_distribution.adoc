=== Distribution

Kurzdefinition::
Eine Distribution ist eine konkrete technische Bereitstellungsform eines Datensatzes oder einer Ausgabe.

Erklärung::
Sie beantwortet die Frage: Wie kann ich die Daten beziehen oder nutzen? Ein Datensatz kann mehrere Distributionen haben. Diese enthalten fachlich denselben oder weitgehend denselben Dateninhalt, unterscheiden sich aber in Format, Zugriffsmethode oder technischer Aufbereitung.

Abgrenzung / Verhältnis::
Eine Distribution ist nicht dasselbe wie eine Ausgabe. Eine Ausgabe beschreibt, welcher Datenstand gemeint ist. Eine Distribution beschreibt, in welcher technischen Form dieser Datenstand verfügbar ist.

Beispiele::
* CSV-Datei
* Excel-Datei
* Parquet-Datei
* GeoPackage
* Shapefile
* JSON oder GeoJSON
* RDF/Turtle
* Download-URL
* API-Endpunkt
* WFS
* WMS
* Kartenansicht

Projektregel::
Distributionen beschreiben immer den Zugang oder das Format eines Datensatzes beziehungsweise einer Ausgabe.

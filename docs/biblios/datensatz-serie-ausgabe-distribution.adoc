= Datensatz, Serie, Ausgabe und Distribution
:description: Fachliche und technische Abgrenzung zentraler Metadatenbegriffe.

Diese Seite ordnet die zentralen Metadatenbegriffe ein. Sie ist für Fachstellen, Metadatenverantwortliche, Entwicklung und Betrieb relevant.

== Datenthema

Ein Datenthema ist die fachliche, für Nutzende verständliche Beschreibung eines Datenangebots im Datenportal. Es ist primär ein fachlicher Portalbegriff.

Gegenüber Fachstellen und Nutzenden sprechen wir vorzugsweise von Datenthema, wenn das fachliche Datenangebot gemeint ist.

== Datensatz

Ein Datensatz ist eine klar beschriebene Sammlung von Daten, die als fachliche und organisatorische Einheit publiziert, gepflegt und gefunden werden kann.

Ein Datensatz hat eigene Metadaten, zum Beispiel Titel, Beschreibung, Herausgeber, Zuständigkeit, Aktualisierungsfrequenz, thematische Einordnung, räumliche und zeitliche Abdeckung sowie Zugangs- und Nutzungsbedingungen.

Ein Datensatz ist noch nicht zwingend eine Datei. Er beschreibt das Datenangebot als inhaltliche Einheit. Die konkreten Dateien, APIs oder Downloadformate werden als Distributionen beschrieben.

== Datensatz-Serie

Eine Datensatz-Serie ist eine Gruppe von Datensätzen, die zusammengehören und nach einem wiederkehrenden Muster publiziert werden.

Serien entstehen oft durch periodische Publikation, wiederkehrende Erhebungen, Jahresstände, Stichtage oder fortlaufende Versionen.

.Beispiele
* Orthofotos Kanton Solothurn mit den Ausgaben 2021, 2023 und 2025.
* Einwohnerstatistik mit den Ausgaben 2022, 2023 und 2024.
* Gemeindefinanzen nach Rechnungsjahr.

Eine Datensatz-Serie ist eine übergeordnete fachliche Klammer. Sie ist nicht einfach ein ZIP mit mehreren Dateien.

== Ausgabe

Eine Ausgabe ist ein einzelner konkreter Datensatz innerhalb einer Datensatz-Serie.

Eine Ausgabe kann sich durch Jahr, Stichtag, Erhebungsperiode, Version, Publikationslauf oder Datenstand unterscheiden. Fachlich ist eine Ausgabe ein Datensatz. Sie kann wiederum mehrere Distributionen haben, zum Beispiel CSV, GeoPackage, WMS oder API.

== Distribution

Eine Distribution ist eine konkrete technische Bereitstellungsform eines Datensatzes oder einer Ausgabe.

Ein Datensatz kann mehrere Distributionen haben. Diese enthalten fachlich denselben oder weitgehend denselben Dateninhalt, unterscheiden sich aber in Format, Zugriffsmethode oder technischer Aufbereitung.

[IMPORTANT]
====
Eine Distribution ist nicht dasselbe wie eine Ausgabe. Eine Ausgabe beschreibt, welcher Datenstand gemeint ist. Eine Distribution beschreibt, in welcher technischen Form dieser Datenstand verfügbar ist.
====

== Entscheidungsregeln

[cols="1,3",options="header"]
|===
|Begriff |Verwendung

|Datenthema
|Wenn das fachliche Datenangebot gemeint ist und die Formulierung für Fachstellen oder Nutzende verständlich sein soll.

|Datensatz
|Wenn das Katalogobjekt, die Metadaten-Einheit oder eine DCAT-nahe Modellierung gemeint ist.

|Datensatz-Serie
|Wenn mehrere zusammengehörige Datensätze oder Ausgaben nach einem wiederkehrenden Muster publiziert werden.

|Ausgabe
|Wenn ein konkreter Jahrgang, Stichtag, Datenstand oder Publikationslauf innerhalb einer Serie gemeint ist.

|Distribution
|Wenn ein Format, Download, Dienst, API oder eine sonstige technische Bereitstellungsform gemeint ist.
|===
